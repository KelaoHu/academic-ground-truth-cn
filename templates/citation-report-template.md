# 引用决策报告模板（citation-report.md）

> 本模板是 skill 的唯一主输出形态。生成时替换全部尖括号内容；状态字段取值规则：`已核验`／`已核验·<待补维度>（<原因>）`（待补维度限：版本信息／刊名／年份／正文页码／原刊具体页码）／`未核实（<原因>）`／`不能使用（<原因>）`。末尾的填充示例是虚构演示，格式供参照，内容不得照搬。

## 填充示例（虚构演示，仅示格式）

### 3.1 论断 C1

- **正文原句**："礼治是乡土社会的秩序基础。"
- **论断类型**：观点转述
- **建议文献（已核验条目）**：费孝通：《乡土中国 生育制度》，北京：北京大学出版社，1998年。
- **元数据确证方式**：缺版权页。使用者陈述（2025-01-XX：购自旧书网，1998年版）＋外部目录核对（国家图书馆 OPAC，2025-01-XX）；版本同一性结论：未确证（外部目录无该版预览可比对）。
- **版本信息（据上述确证来源）**：费孝通著；北京大学出版社 1998 年；版次未见。
- **定位结果**：相关论述位于该书第 51 页；文件页序→印页码映射：PDF 第 60 张 = 书第 51 页，偏移 +9。
- **核验记录**：
  - R1 文本定位：检索"礼治"命中 12 页，缩小至第 49—53 页（按印页码）。
  - R2 图像核对与语境判断：
    - R2a 逐字比对：无直接引语，转述语义一致。
    - R2b 整页阅读：第 51 页该段无"在一定条件下"类限定语；系作者本人观点，非转述第三方。
    - R2c 章节语境阅读：所在小节为〈礼治秩序〉全节，原文以"人治与礼治"对比立论，正文论断与该节核心论点一致；已读完整章确认无相反表述。
    - 页籍确认：该页属正文第四章。
  - R3 页码校准：页面下角印页码"51"；第 50、52 页连续；目录标注第四章起始页与实测偏移一致。
  - R4 元数据核对：文件无版权页；书名页亦缺；按降级流程执行，结论见"元数据确证方式"。
  - R5 反证核查：换用"礼治社会 乡土"重检，无更贴合页面；全书单卷，无同名异章；页眉信息与 1998 年版相符。
- **语境判断结论**：原句在该书语境中被无条件支持，系作者本人观点。
- **适配性论证**：该段为原著核心论证而非转述他人，权威直接；支撑力度足够，无过度声称。
- **原句调整建议**：不调整。
- **脚注（首次引用）**：参见费孝通：《乡土中国 生育制度》，北京：北京大学出版社，1998年，第51页。　—— 附于正文"……礼治是乡土社会的秩序基础。"之后
- **脚注（再次引用）**：参见费孝通：《乡土中国 生育制度》，第51页。
- **疑似自引**：未知
- **证据路径**：`citation-evidence/fei-xx-1998/p51.png`、`excerpt-p51.txt`、`meta.md`
- **状态**：已核验·版本信息（文件缺版权页，经使用者陈述＋国图 OPAC 外部核对，同一性未确证）
